¿Qué necesitan para cotizar una pieza 3D?

Una foto, dibujo o archivo de referencia; las medidas principales; la cantidad y una breve explicación del uso. Si aún no tienes todo, podemos iniciar con la información disponible.

¿Pueden diseñar una pieza si no tengo el modelo?

Sí. Podemos construir el modelo a partir de medidas, referencias y requerimientos. El alcance del diseño se define antes de comenzar.

¿Trabajan piezas únicas y producciones cortas?

Sí. La impresión 3D permite desarrollar desde una unidad para validar un concepto hasta series cortas bajo pedido.

¿Qué tipo de soluciones digitales desarrollan?

Landing pages, sistemas web de gestión y automatizaciones. La arquitectura y las funcionalidades se definen según el proceso que necesitas mejorar.

¿Cómo se define el tiempo y el valor del proyecto?

Dependen de la complejidad, materiales, cantidad, validaciones y entregables. Después de entender la necesidad presentamos un alcance y una cotización claros.
