# VillaTech Dev

Plataforma web modular desarrollada con Django y React.

## Objetivo

Construir una plataforma escalable para VillaTech que permita integrar:

- Servicios de impresión 3D.
- Catálogo de productos.
- Servicios de desarrollo de software.
- Portafolio.
- Noticias o blog.
- Futuras funcionalidades de ecommerce y punto de venta.

## Stack inicial

### Backend
- Python 3.12.4
- Django
- Django REST Framework

### Frontend
- React
- JavaScript

### Control de versiones
- Git
- GitHub

## Estado

Proyecto en etapa inicial de configuración.
